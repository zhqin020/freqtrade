# Freqtrade 策略库分析文档

> 本文档对 `user_data/strategies` 目录下的主要策略进行逐个分析，涵盖简介、特点、原理、主要参数及推荐程度，便于快速了解和选择合适的量化策略。

---

## 1. AlexStrategyFinalV90
- **简介**：基于 LSTM 神经网络回归模型的预测型策略，结合多种技术指标归一化后加权聚合，适合 AI 量化实验。
- **特点**：
  - 利用 LSTM 模型预测目标分数，买卖决策基于预测分数阈值。
  - 多指标归一化加权（如 MA、MACD、RSI、BB宽度等）。
  - 动态权重调整，市场状态过滤，波动率调整。
  - 支持多头和空头，适合1小时周期。
- **主要参数**：
  - threshold_buy/sell：买卖阈值
  - w0-w8：各指标权重
  - trailing_stop 相关参数
- **原理**：通过 LSTM 预测未来收益分数，结合多指标归一化聚合，动态调整权重和市场状态过滤，最终输出买卖信号。
- **推荐程度**：⭐⭐⭐⭐（适合有AI基础、追求高阶量化的用户）

## 2. Bandtastic
- **简介**：基于多组布林带、EMA、RSI、MFI等指标的多参数可调策略，适合15分钟级别高频交易。
- **特点**：
  - 多组布林带（1-4倍标准差）作为买卖触发条件。
  - EMA、RSI、MFI等多参数可超参数优化。
  - 支持trailing stop，ROI分段。
- **主要参数**：
  - buy/sell_fastema、slowema、rsi、mfi
  - 各指标是否启用（如buy_rsi_enabled等）
  - buy/sell_trigger（布林带触发层级）
- **原理**：通过多重布林带突破、均线金叉、RSI/MFI超卖超买等多重条件组合，灵活调参，适合高频回测和优化。
- **推荐程度**：⭐⭐⭐⭐⭐（适合新手和进阶用户，易于理解和调优）

---

## 3. BreakEven
- **简介**：极简“保本”策略，主要用于快速平掉盈利单，等待亏损单回本。
- **特点**：
  - 不主动买入，仅靠ROI和止损自动卖出。
  - 适合临时切换，快速清仓。
- **主要参数**：
  - minimal_roi
  - stoploss
- **原理**：无买入信号，卖出信号由ROI和止损自动触发，适合“保本退出”场景。
- **推荐程度**：⭐⭐⭐（适合特殊需求，非主动交易）

---

## 4. CustomStoplossWithPSAR
- **简介**：以PSAR为核心的自定义止损策略，演示如何实现动态止损。
- **特点**：
  - 止损点随PSAR动态调整。
  - 买入信号为PSAR上穿。
  - 卖出信号禁用，完全依赖止损。
- **主要参数**：
  - stoploss
  - use_custom_stoploss
- **原理**：每根K线根据PSAR调整止损，适合演示自定义止损机制。
- **推荐程度**：⭐⭐⭐（适合学习自定义止损，实盘需完善）

## 5. Diamond
- **简介**：极简“裸K”策略，完全不依赖技术指标，所有信号基于OHLCV原始数据。
- **特点**：
  - 买卖信号基于K线数据的交叉。
  - 所有参数均可超参数优化。
  - 适合5分钟级别。
- **主要参数**：
  - buy/sell_fast_key、slow_key、vertical_push、horizontal_push
- **原理**：通过K线数据的交叉和推移，寻找买卖点，适合裸K派和参数优化实验。
- **推荐程度**：⭐⭐⭐（适合参数优化和裸K实验）

## 6. E0V1E
- **简介**：多指标多周期混合策略，支持多头和空头，带有自定义止损和多重卖出逻辑。
- **特点**：
  - 多周期RSI、SMA、CTI等指标组合。
  - 多空双向，支持自定义止损和多种卖出条件。
  - 参数丰富，适合深度优化。
- **主要参数**：
  - buy/short_rsi_fast_32、rsi_32、sma15_32、cti_32等
  - sell_fastx、sell_loss_cci、sell_loss_cci_profit
- **原理**：多指标组合判断买卖点，结合多重止盈止损逻辑，适合复杂行情。
- **推荐程度**：⭐⭐⭐⭐（适合进阶用户，需调参）

## 7. FixedRiskRewardLoss
- **简介**：基于ATR动态止损和固定风险收益比的策略，强调风控。
- **特点**：
  - 进场时根据ATR和负峰动态设定初始止损。
  - 达到风险收益比后自动上移止损。
  - 支持break even（保本）机制。
- **主要参数**：
  - risk_reward_ratio
  - set_to_break_even_at_profit
- **原理**：以ATR为基础动态调整止损，严格执行风险收益比，适合风控优先的交易者。
- **推荐程度**：⭐⭐⭐⭐（适合重视风控的用户）

---

## 8. GodStra
- **简介**：基于ta-lib全指标特征的多条件组合策略，参数极为丰富，适合深度优化。
- **特点**：
  - 自动添加所有ta特征，买卖条件可灵活组合。
  - 支持多种操作符（>, <, =, CA, CB等），可实现复杂逻辑。
  - 适合12小时级别，建议配合AgeFilter和小max_open_trades。
- **主要参数**：
  - buy/sell-cross-0、buy/sell-indicator-0、buy/sell-oper-0等
  - minimal_roi、stoploss、trailing_stop相关
- **原理**：通过多组指标和操作符灵活组合，适合参数深度优化和复杂行情。
- **推荐程度**：⭐⭐⭐⭐⭐（适合高级用户和策略开发者）

## 9. Heracles
- **简介**：GodStra的“极简”子策略，仅用1组基因参数，主打极简与高效。
- **特点**：
  - 仅用Donchian Channel和Keltner Channel两种波动率指标。
  - 通过两指标的比值区间判断买入。
  - 适合4小时周期，参数极少，易于超参。
- **主要参数**：
  - buy_div_min, buy_div_max, buy_indicator_shift, buy_crossed_indicator_shift
- **原理**：两种通道指标的比值落在指定区间时买入，无主动卖出信号。
- **推荐程度**：⭐⭐⭐（适合极简风格和参数优化实验）

- **推荐程度**：⭐⭐⭐（适合新手和择时实验）

## 23. ElliotV5_SMA
- **简介**：典型的均线回踩 + EWO 趋势过滤策略，主做5分钟短线，通过“低吸进场、均线上方离场”来捕捉波段。
- **特点**：
  - 买入使用两套并行条件：
    - 条件A：价格低于买入均线偏移 + EWO强势 + RSI不过热。
    - 条件B：价格低于买入均线偏移 + EWO极弱（抄底分支）。
  - 卖出逻辑较简单：价格高于卖出均线偏移即触发卖出。
  - 启用了 trailing stop（需先达到偏移阈值后才跟踪），与 ROI/固定止损共同构成退出体系。
  - 策略名带“SMA”，但主交易均线实际使用 EMA；仅 EWO 计算中使用了 SMA 差值。
  - 代码里存在信息性周期定义（1h）和大量额外指标函数，但核心交易逻辑并未实际使用这些信息。
- **主要参数**：
  - `base_nb_candles_buy` / `base_nb_candles_sell`：买卖均线周期。
  - `low_offset` / `high_offset`：入场折价与出场溢价偏移。
  - `ewo_high` / `ewo_low`：EWO 高位趋势阈值与低位抄底阈值。
  - `rsi_buy`：强势分支的 RSI 上限过滤。
  - `minimal_roi`、`stoploss`、`trailing_stop_positive(_offset)`：核心风控与止盈参数。
- **原理**：
  - 先用 EWO 判断市场所处区间（趋势偏强或超弱反弹潜在区）。
  - 在价格回踩到买入 EMA 下方一定偏移时入场，提高盈亏比。
  - 出场端以“价格重回卖出 EMA 上方偏移”为主，叠加 ROI、固定止损与追踪止盈做多层退出。
- **适用行情与风险**：
  - 更适合有波动的趋势/反弹行情，在单边阴跌或低波动震荡中可能频繁试错。
  - `startup_candle_count = 2000` 对数据长度要求较高，实盘和回测要确保足够历史K线。
  - 当前参数组合偏激进（止损较大、短周期高频），建议先做分市场回测与 walk-forward 验证。
- **推荐程度**：⭐⭐⭐⭐（适合有一定回测经验、愿意持续调参与风控约束的用户）
