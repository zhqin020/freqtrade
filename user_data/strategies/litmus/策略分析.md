# Litmus 策略库分析文档

> 本文档对 `user_data/strategies/litmus` 目录下的主要策略进行逐个分析，涵盖简介、特点、原理、主要参数及推荐程度，便于快速了解和选择合适的策略。
>
> 说明：Litmus 系列大多依赖 FreqAI（`self.freqai.start(...)`）与自定义标签逻辑，不建议脱离对应配置文件直接实盘。

---

## 1. LitmusSimpleStrategy
- **简介**：Litmus 系列的基础元策略，核心是“规则初筛 + FreqAI 元分类确认 + 自定义出场/仓位”。
- **特点**：
  - 提供完整的 FreqAI 特征工程（技术指标、时间周期特征、BTC 相对特征、可选协整特征）。
  - 以 `primary_enter_long/short` 作为原始触发，再由 `win_long/win_short` 与动态阈值二次确认。
  - 支持 `custom_exit`（弱/强对手信号退出）、Kelly 仓位管理、加仓逻辑。
  - 支持双向交易（`can_short = True`）。
- **主要参数**：
  - `minimal_roi`, `stoploss`
  - `entry_parameters.smoothing_window`
  - `exit_parameters.*`
  - `bet_sizing.enabled`、`fixed_leverage`
- **原理**：先构造规则侧初始信号（primary），再用 FreqAI 模型概率过滤，最后由 `custom_exit/custom_stoploss/adjust_trade_position` 进行动态风控与仓位控制。
- **推荐程度**：⭐⭐⭐⭐⭐（适合熟悉 FreqAI 的中高级用户，适合作为 Litmus 基座）

---

## 2. LitmusBBStrategy
- **简介**：基于布林带 + RSI 拐点的基础信号策略，继承 `LitmusSimpleStrategy` 的元模型过滤与风控框架。
- **特点**：
  - 长多信号：低点触及下轨 + RSI 上拐。
  - 做空信号：高点触及上轨 + RSI 下拐。
  - 使用 `shift(1)` 将主入场信号顺延一根K线，降低未来函数风险。
  - 启用自定义止损和 DCA（`position_adjustment_enable = True`）。
- **主要参数**：
  - 布林带窗口与标准差（固定为 `window=25, std=1.9`）
  - `use_custom_stoploss`, `max_entry_position_adjustment`
- **原理**：先通过布林带极值和 RSI 反转生成 primary 信号，再交由元分类模型筛选高置信交易。
- **推荐程度**：⭐⭐⭐⭐（适合“均值回归 + AI过滤”的进阶用户）

---

## 3. LitmusBBTrendStrategy
- **简介**：BBTrend 版本更偏趋势跟随，使用布林中轨与 RSI 均线动量来触发信号。
- **特点**：
  - 多头：价格在中轨上方且 RSI 均线拐头向上。
  - 空头：价格在中轨下方且 RSI 均线拐头向下。
  - primary 侧不主动给出出场信号（`primary_exit_long/short = False`），更依赖元策略退出。
- **主要参数**：
  - `rsi` 与 `rsi-ma`（7周期）
  - `use_custom_stoploss = True`、DCA 开启
- **原理**：将布林带由反转逻辑改为趋势过滤逻辑，再由 FreqAI 概率层做二次确认。
- **推荐程度**：⭐⭐⭐⭐（适合趋势中短线，较 BB 版本更偏顺势）

---

## 4. LitmusClucStrategy
- **简介**：融合 Cluc 风格均值回归结构的策略（EMA + BB + 量能过滤），并接入 Litmus 元过滤。
- **特点**：
  - 多头：价格低于 `ema100` 且明显跌破下轨。
  - 空头：价格高于 `ema100` 且明显突破上轨。
  - 出场使用中轨回归。
  - ROI 较快（`minimal_roi = {"0": 0.01}`），偏短平快。
- **主要参数**：
  - `ema100`、布林带偏移比例（0.985 / 1.015）
  - volume 过滤条件（30周期均量）
- **原理**：使用“偏离-回归”结构捕捉超跌/超涨回归，再叠加 FreqAI 模型筛选。
- **推荐程度**：⭐⭐⭐（适合震荡行情实验，趋势单边时需谨慎）

---

## 5. LitmusSARStrategy
- **简介**：以 PSAR + EMA 趋势过滤为核心的方向策略。
- **特点**：
  - 多头：SAR 上穿 + 价格位于 EMA200 上方。
  - 空头：SAR 下穿 + 价格位于 EMA200 下方。
  - 结构简洁，作为规则侧 primary 信号较直观。
- **主要参数**：
  - `ta.SAR(... acceleration=0.01, maximum=0.2)`
  - `ema_200`（代码中 period=100 命名为 ema_200）
- **原理**：用 SAR 方向翻转产生入场，再由元模型做置信度过滤。
- **推荐程度**：⭐⭐⭐（适合趋势过滤场景；需重点回测出场逻辑一致性）

---

## 6. LitmusScalpStrategy
- **简介**：短线剥头皮策略，依赖 EMA 区间 + ADX 强趋势 + 随机指标金叉/死叉。
- **特点**：
  - 多头：开盘价低于 EMA low，且 ADX 强、K/D 低位金叉。
  - 空头：开盘价高于 EMA high，且 ADX 强、K/D 高位死叉。
  - 出场采用 EMA 触碰或随机指标超阈值。
- **主要参数**：
  - `EMA(5)`、`ADX > 30`
  - `STOCHF(5,3,3)` 的 `fastk/fastd` 区间阈值
- **原理**：在强趋势条件下捕捉局部回撤反弹/回落切入点，追求高频次小波段。
- **推荐程度**：⭐⭐⭐（适合高频短线测试，手续费与滑点敏感）

---

## 7. LitmusTrendScalpStrategy
- **简介**：趋势 + 动量短线混合策略，用 SMA 结构定义方向，用 SMI 变化触发入场。
- **特点**：
  - 趋势判定：`sma-21` 相对 `sma-50` 的上下关系。
  - 入场触发：SMI 动量信号上/下拐。
  - 启用自定义止损与 DCA，`startup_candle_count=400` 对历史数据要求高。
- **主要参数**：
  - `SMA(21, 50, 200)`、`SMI(k=9, d=3)`
  - `use_custom_stoploss = True`、`max_entry_position_adjustment = 2`
- **原理**：趋势先行过滤，动量转折做触发，元模型负责进一步提升信号质量。
- **推荐程度**：⭐⭐⭐⭐（适合趋势行情中的短线进出）

---

## 8. LitmusVulcanStrategy
- **简介**：偏经典趋势结构，结合 RSI 与 SMA 斜率、随机指标和突破失败检测。
- **特点**：
  - 多头：价格在 SMA 上方，SMA 连续走强，RSI > RSI 均线且 >50。
  - 空头：价格在 SMA 下方，SMA 连续走弱，RSI < RSI 均线且 <50。
  - 出场使用随机指标卖出交叉或高低点突破失败（lower_low/higher_high）。
  - 止损较宽（`stoploss = -0.25`）。
- **主要参数**：
  - `SMA(23)`、`RSI(14)` + RSI SMA(50)
  - `STOCH` 参数（14/4/6）
- **原理**：以趋势一致性作为主筛选，辅以随机指标动量转弱做退出。
- **推荐程度**：⭐⭐⭐（适合趋势段持仓，但风控参数偏激进）

---

## 9. LitmusMLDPStrategy
- **简介**：较早期的“双层模型”方案：主模型识别峰谷（zigzag），元模型判断入场后胜率。
- **特点**：
  - 使用 `zigzag + nearby_extremes` 标注主目标。
  - 使用 TBM（三重障碍）构造 secondary/meta 目标。
  - 入场基于 `minima_slow/maxima_slow` 与 `a_win_long/a_win_short` 双条件。
  - 自定义止损按当前利润动态收紧（约利润的一半，限 1%-3%）。
- **主要参数**：
  - `primary_target_parameters.*`
  - `secondary_target_parameters.*`
  - `trigger_parameters.smoothing_window`
- **原理**：先预测“位置”（是不是局部低/高点），再预测“质量”（该位置进场是否高胜率）。
- **推荐程度**：⭐⭐⭐⭐（适合研究多层标签与元学习）

---

## 10. LitmusMinMaxStrategy
- **简介**：以峰谷分类为核心的 MinMax 策略，重点关注 minima/maxima 概率阈值触发。
- **特点**：
  - primary 目标为 `minima/maxima/not_minmax`。
  - 入场条件较直接：`minima` 或 `maxima` 超过动态阈值即触发。
  - 可选出场触发（取决于 `exit_parameters.exit_trigger_enabled`）。
- **主要参数**：
  - `primary_target_parameters`（zigzag, nearby, offset）
  - `entry_parameters.smoothing_window`
  - `exit_parameters.*`
- **原理**：将市场分为“潜在低点/高点/非拐点”，按模型输出概率阈值决定做多或做空。
- **推荐程度**：⭐⭐⭐⭐（适合研究“拐点分类”与阈值交易）

---

## 11. LitmusMinMaxTrendStrategy
- **简介**：在 MinMax 基础上增加元模型标签（`&-meta_target`），更强调入场质量过滤。
- **特点**：
  - `nearby_peaks` 决定 primary long/short 候选。
  - `a_win_long/a_win_short` 与动态阈值共同决定最终入场。
  - 开启 `use_custom_stoploss = True`，并支持“退出信号触发时快速收紧止损”。
- **主要参数**：
  - `entry_parameters.smoothing_window`
  - `exit_parameters.exit_trigger_enabled / sl_exit_trigger_enabled`
- **原理**：先做峰谷定位，再用元分类模型过滤“可交易拐点”，提升信号质量。
- **推荐程度**：⭐⭐⭐⭐⭐（Litmus 中较完整、实战导向较强的架构之一）

---

## 12. LitmusMinMaxBroadClassificationStrategy
- **简介**：多目标广义分类版本，分别建模入场、出场、错过出场等多种行为阈值。
- **特点**：
  - 多组标签（`target_0`, `target_1`）+ 多组阈值（entry/exit/missed exit）。
  - 出入场逻辑细分为 long/short 与 normal/missed 两层。
  - 带保护机制参数（`DI_threshold`、`do_predict`）可启用。
  - 默认配置中 timeframe 为 3m，更偏高频。
- **主要参数**：
  - 超参数：`long_entry_mul`, `short_entry_mul`, `long_exit_mul`, `short_exit_mul`
  - 保护参数：`DI_threshold_enabled`, `do_predict_enabled`
  - 标签参数：`labeling_parameters.*`
- **原理**：通过多任务分类同时学习“何时进、何时出、何时补救出场”，以提升复杂行情下的决策精细度。
- **推荐程度**：⭐⭐⭐⭐⭐（高级策略研究与超参优化首选，复杂度最高）

## 13. 目录中的配置与辅助文件（非策略主体）
- `config.LitmusMLDP.json`：5m 配置模板，适配多数 Litmus 元策略。
- `config.LitmusMinMaxBroadClassification.json`：3m 配置模板，适配 BroadClassification。
- `config_litmus.json`：当前内容指向 `NostalgiaForInfinityX`，不属于 Litmus 策略本体。
- `config.exchange_secret.json`：交易所私钥配置（敏感信息容器）。
- `deprecated/`：历史实验或废弃版本目录，建议与主策略分离维护。

---

## 综合建议（选型）
- **新手入门 Litmus**：`LitmusBBStrategy`、`LitmusTrendScalpStrategy`
- **中阶研究（峰谷 + 元模型）**：`LitmusMinMaxStrategy`、`LitmusMLDPStrategy`
- **高阶实战与优化**：`LitmusMinMaxTrendStrategy`、`LitmusMinMaxBroadClassificationStrategy`
- **谨慎使用**：`LitmusVulcanStrategy`（止损较宽）、`LitmusScalpStrategy`（交易频率高，对费用敏感）
